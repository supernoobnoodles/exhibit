Things to Know

Before trying the app

This is a student project, there are a limited number of pills it can recognize (but for packages, it can recognize almost all.)

The list of pills it can identify are shown below.

The first identification might take a while, but for subsequent identifications, it will be a couple of seconds. This is because the server has a cold start.

When taking a picture, focus the medication inside the square guide. Make sure there is good lighting and pill features are clearly seen.

Why Package Recognition Works Better

Medication packages have standardized designs, clear text, and consistent branding that make them ideal for AI recognition. Unlike individual pills which can vary in lighting and positioning, packages provide multiple visual cues for accurate identification.
